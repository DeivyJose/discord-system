# The Clock

The Clock es un ecosistema comunitario construido alrededor de Discord.

## Componentes principales

- Compai: bot oficial de Discord.
- API: backend seguro.
- Web: panel administrativo y portal de usuarios.
- PostgreSQL: base de datos principal.
- Sistema de permisos y auditoría.
- Comunidades y departamentos.
- Empleos, nómina y Maricoins.
- Moderación y sistema disciplinario.
- CDN - Noticias y eventos.
- Campus RD.
- Gaming y Basketball.
- Salas de voz temporales.
- Notificaciones y automatizaciones.

## Estado
